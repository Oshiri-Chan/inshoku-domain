# 第11章 用語集

本資料に出てくる用語を、分野別にまとめました。「扱う章」の列から、詳しい説明のある章に移動できます。**この章で扱うこと**は、用語の定義の確認と、似た用語の区別です。たとえば「原価率」と「粗利率」、「材料費」と「仕入額」、「稼働率」と「回転率」は、混同すると数字の読み方が変わります。章末には五十音順の索引を置いています。

## 11.7 よくある誤解

用語そのものを取り違えると、計算の意味が変わります。よくある混同を並べます。

| 誤解 | 実際 |
| --- | --- |
| 原価率と粗利率は別々に測る数字 | 1 − 原価率 = 粗利率です。片方が分かればもう片方は決まります |
| 材料費は仕入額と同じ | 材料費は**使った額**です。在庫の増減を調整します（11.1 棚卸し） |
| 稼働率と回転率は同じ | 稼働率は**席時間**の使用率、回転率は**1席あたりの人数**です。滞在時間を挟んで変換できますが、値は違います |
| 機会損失は廃棄と同じ損失 | 廃棄は材料費の損失、機会損失は**粗利**の損失です。金額の大きさが違います |
| 限界利益と営業利益は同じ | 限界利益は変動費だけを引いた値。固定費を引くと営業利益です |
| 安全在庫は多ければ安全 | 多いほど品切れは減りますが、廃棄と資金の固定が増えます |
| 歩留まりは調理技術の問題だけ | 仕入れの等級・鮮度・発注単位によっても変わります |
| ロス率はロス全体を示す | 棚卸ロスなど、記録に載らないロスはロス率に出ません |
| 会員数が増えれば売上が増える | 会員数ではなく、会員売上比率と来店頻度を見ます |

## 11.8 この章の要点

- 用語は**式で確認する**と混同を防げます。原価率と粗利率、稼働率と回転率は、式が違います。
- 材料費（使った額）と仕入額（買った額）は別物です。在庫の増減を挟んで一致します。
- 損失を比べるときは、**材料費（廃棄）か粗利（機会損失）か**をそろえてから計算します。
- 定義が揺れやすい用語（リピート率、客数、稼働率）は、**自店の定義を文書に固定**してから使います。
- 法規・制度の用語は、本資料で確認できた範囲の定義です。**制度は改正されるため、必ず最新の一次資料で確認**してください。

## 11.9 自店で確認すること

- [ ] 自店で使う用語の定義（客数、組数、稼働率、リピート率）を1枚にまとめている
- [ ] POS や表計算の集計定義が、その1枚と一致している
- [ ] 「原価率」と「粗利率」を、同じ数字の裏返しとして扱えている
- [ ] 材料費を仕入額ではなく、在庫を調整した「使った額」で計算している
- [ ] 廃棄の損失と機会損失を、それぞれ材料費・粗利で計算し分けている
- [ ] 発注点・安全在庫の意味を、発注する人が説明できる
- [ ] 法規・制度に関する用語は、確認日と出典をセットで記録している
- [ ] 用語の定義を変更したとき、変更履歴を残している

## 11.10 演習

### 問1 原価率と粗利率

1. 原価率が 38.0% のとき、粗利率は何%ですか。
2. 粗利率が 72.0% のとき、原価率は何%ですか。
3. 売上 2,500,000円、原価率 38.0% のとき、粗利額はいくらですか。

**解答**

1. 粗利率 = 1 − 0.38 = 0.62 → **62.0%**。
2. 原価率 = 1 − 0.72 = 0.28 → **28.0%**。
3. 粗利額 = 2,500,000 × 0.62 = **1,550,000円**（検算: 材料費 2,500,000 × 0.38 = 950,000円、2,500,000 − 950,000 = 1,550,000円）。

### 問2 材料費と仕入額

期首在庫 200,000円、当期仕入 1,600,000円、期末在庫 250,000円、売上 5,000,000円でした。

1. 材料費と原価率を計算してください。
2. 仕入額をそのまま材料費とした場合の原価率との差を、ポイントと金額で示してください。
3. この差が生まれる理由を、「在庫」という語を使って説明してください。

**解答**

1. 材料費 = 200,000 + 1,600,000 − 250,000 = **1,550,000円**。原価率 = 1,550,000 ÷ 5,000,000 = **31.0%**。
2. 1,600,000 ÷ 5,000,000 = **32.0%**。差は **1.0ポイント**、金額では 1,600,000 − 1,550,000 = **50,000円**です。
3. 仕入れた分のうち、期末に在庫として残った 250,000円は「まだ使っていない」費用です。期首に残っていた 200,000円は、前期に買って今期使った分です。**使った額**にするには、仕入額に期首在庫を足し、期末在庫を引きます。

### 問3 稼働率と回転率

席数20席、1日の営業時間10時間の店で、ある日の利用が60組、1組あたり平均2人、平均滞在時間1時間でした。

1. 延べ使用席時間を計算してください（1人が1時間使うと1席時間とします）。
2. 回転率と席稼働率を計算してください。
3. 稼働率を 80.0% にするには、平均滞在時間と人数が同じ条件で何組必要ですか。
4. 「稼働率は高いが回転率が低い」状態は、どんな状態ですか。

**解答**

1. 延べ使用席時間 = 60組 × 2人 × 1時間 = **120席時間**。上限は 20席 × 10時間 = 200席時間です（120 ÷ 200 = 60.0% で上限内）。
2. 回転率 = 120人 ÷ 20席 = **6.0回転**。席稼働率 = 120 ÷ (20 × 10) = 120 ÷ 200 = **60.0%**。
3. 必要な席時間 = 200 × 0.80 = 160席時間。1組あたり2人 × 1時間 = 2席時間なので、160 ÷ 2 = **80組**（現状60組から+20組）。
4. 稼働率が高く回転率が低い状態は、**少数の組が長く席を使っている**状態です。席は埋まっているのに新しい組が入れません。長時間の滞在が客単価の高さで見合っていれば問題ありませんが、意図していないなら、提供時間・退席の声かけ・席の構成を見直します。逆に、稼働率が低く回転率が高い状態は、**短時間で回っているが席が余っている**状態です。
