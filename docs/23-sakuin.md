# 第23章 索引

## 23.1 この索引の使い方

この章は、本書を「辞書」として使うための入口です。用語・トピック・図表・章末問題・ケースの5種類から、該当する章と節に移動できます。

**第21章との役割分担**は、次のとおりです。

| 引きたいもの | 使う索引 | 置き場所 |
| --- | --- | --- |
| 用語の定義・読み・扱う章 | 用語の五十音順索引 | [第21章 21.7 五十音順索引](21-yougo.md) と各分野の用語一覧 |
| 概念・論点から章を探す | トピック索引 | この章の 23.2 |
| 図や表を探す | 図表索引 | この章の 23.3 |
| 演習問題を探す | 章末問題索引 | この章の 23.4 |
| ケースの場面から章を探す | ケース索引 | この章の 23.5 |

**用語は第21章、それ以外は第23章**です。同じ内容を二重に載せないため、この章には用語の定義を書いていません。語の意味を知りたいときは、まず [第21章](21-yougo.md) を開いてください。

### 使い方の手順

1. **言葉は分かるが、章が分からない**: 23.2 のトピック索引を引きます。トピックは五十音順です。
2. **言葉そのものが分からない**: [21.7 五十音順索引](21-yougo.md) で読みから引き、そこに書かれた章へ移動します。
3. **図で構造をつかみたい**: 23.3 の図表索引を引きます。「種類」が「図」なら Mermaid 図、「表」なら一覧表です。
4. **手を動かして確かめたい**: 23.4 の章末問題索引を引きます。章ごとに3問あり、うち1問は計算問題です。
5. **店の1年を追いたい**: 23.5 のケース索引を引きます。節ごとに関連する章を示しています。

### 表記について

- 章番号とファイル名は [OUTLINE.md](../OUTLINE.md) の部立てに従っています。
- 「節」の列は、その章の見出し番号です。章のファイルを開き、同じ番号の見出しを探してください。
- リンクはすべて相対パスです。章の列のリンクから、その章のファイルに移動できます。
- **この索引には数値を載せていません。** 金額・率・年数などの値は、各章の本文と表を参照してください。索引は「どこに書いてあるか」だけを示します。
