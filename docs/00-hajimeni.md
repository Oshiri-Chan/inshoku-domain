# はじめに

## この本の目的

飲食店は、誰でも始められる商売のように見えます。実際、開業に必要な資格は限られ、小さな店舗から始められます。しかし、**続けられる店は多くありません**。

その理由は、努力や才能の問題だけではありません。飲食店には、**構造的に厳しい仕組み**があります。

- 席と時間は在庫として保存できない（今日の空席は明日に売れない）
- 固定費（家賃・人件費）が重く、客数が少し落ちるだけで赤字になる
- 食材は傷む。需要予測を外すと、そのまま損失になる
- 現金が手元にあっても、それは支払いに充てるべきお金である

これらは「気合い」では解決しません。**仕組みとして理解し、数字で管理する**必要があります。

この本は、そのための**教科書**です。用語の説明から始めて、計算できるところまで連れていきます。

## 誰のための本か

| 読者 | 使い方 |
| --- | --- |
| 開業を考えている人 | 第1部で構造をつかみ、第2部で開業手続きを確認する |
| 店舗の数字を学びたい人 | 第1部と第19章を読む |
| 飲食店向けのシステムを作る人 | 全体を読み、第8章・第19章の指標定義を仕様の参考にする |
| 経営を支援する人（コンサル・金融・自治体） | 全体を読み、顧客への説明の材料にする |
| 研修・教育の担当者 | 各章の学習目標と章末問題を教材に使う |

## 学習の進め方

各章は、同じ順序で書かれています。

```
この章で扱うこと → 学習目標 → 本文 → ケースの店では
→ よくある誤解 → この章の要点 → 自店で確認すること
→ 章末問題（解答付き） → 参考文献・出典
```

### 学習目標の使い方

各章の冒頭に「学習目標」があります。「〜できる」の形で書かれています。**読む前に目を通し、読み終えたら自分に問い直してください。** 「説明できるか」「計算できるか」を自分で確認するのが、理解の判定になります。

### 章末問題の使い方

各章に3問あります。うち1問は計算問題です。**解答を先に見ずに、紙に書いて解いてください。** 計算問題は、電卓を使って構いません。間違えたら、該当する節に戻って読み直します。

### 「自店で確認すること」の使い方

チェックリストです。開業前・運営中に、実際に確認する項目として使えます。すべてにチェックが付かない状態は、**判断の根拠が揃っていない**状態です。

## 連続ケース「食堂つきかげ」

本書には、架空の店舗「食堂つきかげ」が繰り返し登場します。地方都市の駅前で、昼は定食、夜は居酒屋の二毛作を営む20席の店です。開業から1年までの数字を、各章で使います。

設定は [OUTLINE.md](../OUTLINE.md) の3章、物語は [第22章](22-case.md) にあります。**ケースの数字は設計値であり、実在の店舗の実績ではありません。**

ケースを使う理由は、**章をまたいだ計算がつながる**からです。損益分岐点（第6章）で出した数字を、キャッシュフロー（第7章）で使い、KPI（第19章）で振り返る。同じ店を追うことで、経営が一本の流れとして見えます。

## 本書の限界

正直に書きます。

1. **この本は法的・税務的・会計的な助言ではありません。** 許可申請、労務、税務の判断は、保健所、社会保険労務士、税理士に確認してください。
2. **数値例とケースは説明用の設計値です。** 実在の店舗の実績ではありません。
3. **業界平均の原価率・人件費率は載せていません。** 業態・規模・地域で大きく異なり、単一の平均値を目標にすると判断を誤るためです。代わりに、自店の数字を作る方法を書いています（第3章・第4章）。
4. **法規の情報は、確認できた時点のものです。** 制度は改正されます。必ず最新の一次資料を確認してください。
5. **取得できなかった情報があります。** 業種別の原価率・人件費率の公的統計、開業率・廃業率、営業許可の申請書類の詳細、消防法の用途区分などは「未取得」と明記しています。推測では埋めていません。
