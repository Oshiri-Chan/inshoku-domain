# はじめに — この資料の使い方

飲食店は、誰でも始められる商売のように見えます。実際、開業に必要な資格は限られ、小さな店舗から始められます。しかし、**続けられる店は多くありません**。

その理由は、努力や才能の問題だけではありません。飲食店には、**構造的に厳しい仕組み**があります。

- 席と時間は在庫として保存できない（今日の空席は明日に売れない）
- 固定費（家賃・人件費）が重く、客数が少し落ちるだけで赤字になる
- 食材は傷む。需要予測を外すと、そのまま損失になる
- 現金が手元にあっても、それは支払いに充てるべきお金である

これらは「気合い」では解決しません。**仕組みとして理解し、数字で管理する**必要があります。

## この資料が目指すこと

飲食店経営の基本を、**用語の説明から始めて、計算できるところまで**持っていくことです。

- 専門用語は初出時に説明します。
- 計算式には必ず数値例を付けます。読者が電卓で検算できるようにします。
- 数値には出典と取得日を付けます。出典が確認できない数値は載せません。
- 取得できなかった統計や法規は「未取得」と明記します。推測で埋めません。

**「わかった気になる」資料にはしません。** 曖昧なままにせず、確認できたことと確認できていないことを分けて書きます。

## 各章の構成

各章は、同じ順序で書かれています。

```
導入（この章で扱うこと）
本文（定義 → 計算式 → 数値例 → 表）
よくある誤解
この章の要点
自店で確認すること（チェックリスト）
演習（解答付き）
出典と確度
```

**「自店で確認すること」は、そのまま現場で使えるチェックリスト**です。「演習」は、理解を確かめるための問題です。研修の教材としても使えます。

## この資料の限界

正直に書きます。

1. **この資料は法的・税務的・会計的な助言ではありません。** 許可申請、労務、税務の判断は、保健所、社会保険労務士、税理士に確認してください。
2. **数値例は説明用の仮置きです。** 実在の店舗の実績ではありません。
3. **業界の平均値は、意図的に載せていません。** 原価率や人件費率の「一般的な目安」は、業態・規模・地域で大きく異なります。単一の平均値を目標にすると、かえって判断を誤ります。代わりに、自店の数字を作る方法を書いています。
4. **法規の情報は、確認できた時点のものです。** 制度は改正されます。必ず最新の一次資料を確認してください。

## 続けるために

飲食店経営で最も重要なのは、**測って、振り返って、直す**という循環です。この資料は、その循環を回すための言葉と計算式を提供します。

完璧な計画より、**測れる状態**を作ることが先です。第10章の最後に、その始め方を書いています。
