# 第21章 用語集

本資料に出てくる用語を、分野別にまとめました。「扱う章」の列から、詳しい説明のある章に移動できます。章末には五十音順の索引を置いています。

## 21.1 会計・財務

| 用語 | 定義 | 扱う章 |
| --- | --- | --- |
| 売上高 | 一定期間に販売した金額の合計。飲食店では客が支払った総額 | 1, 2 |
| 客単価 | 1人の客が1回の来店で使った金額。売上 ÷ 客数 | 8 |
| 材料費（食材費） | 提供した料理に使った食材・飲料の原価。仕入額ではなく**使った額** | 3, 16 |
| 原価率 | 材料費 ÷ 売上高。業態で大きく異なる | 3 |
| 粗利（売上総利益） | 売上 − 材料費。人件費や家賃を払う原資 | 1, 2 |
| 粗利率 | 粗利 ÷ 売上。1 − 原価率 | 2 |
| 変動費 | 売上に比例して増減する費用。材料費が代表 | 6 |
| 変動費率 | 変動費 ÷ 売上 | 6 |
| 固定費 | 売上が0でも発生する費用。家賃、正社員給与、リース料など | 5, 6 |
| 限界利益 | 売上 − 変動費。固定費を回収する原資 | 6 |
| 限界利益率 | 限界利益 ÷ 売上。1 − 変動費率 | 6 |
| 営業利益 | 粗利から人件費・家賃・その他経費を引いた残り | 2 |
| 経常利益 | 営業利益に営業外収益を足し、営業外費用を引いたもの | 2 |
| 当期純利益 | 経常利益から特別損益・税金を引いた最終的な利益 | 2 |
| 損益分岐点売上 | 利益がゼロになる売上。固定費 ÷ 限界利益率 | 6 |
| 損益分岐点客数 | 損益分岐点売上 ÷ 客単価。何人必要かの形に直したもの | 6 |
| 安全余裕率 |（実際の売上 − 損益分岐点売上）÷ 実際の売上 | 6 |
| 人件費率 | 人件費 ÷ 売上高。売上水準に左右される | 4 |
| 人時売上 | 売上 ÷ 総労働時間。労働1時間あたりの生産性 | 4 |
| 実質時間単価 | 時給に社会保険料などの事業主負担を加えた、1時間あたりの実質コスト | 4 |
| 家賃比率 |（家賃＋共益費）÷ 売上高 | 5 |
| FL比率 |（材料費＋人件費）÷ 売上高。体質を見る入口。家賃は含まない | 2 |
| 運転資金 | 日々の支払いに必要な資金。固定費と仕入れ支払いから入金を引いた額 | 7 |
| 当座資産 | 現金・預金・売掛金など、すぐ支払いに充てられる資産 | 7 |
| 支払サイト | 仕入れ先への支払までの日数。短いほど資金繰りが厳しい | 7 |
| 営業キャッシュフロー | 営業活動で生まれた現金。税引前利益＋減価償却費−運転資本増加 | 7 |
| 減価償却費 | 設備の取得費用を耐用年数で按分した費用。現金支出ではない | 7 |
| 投資回収期間 | 初期投資 ÷ 年間キャッシュフロー。投資が元取れるまでの年数 | 20 |
| 機会費用 | 別の使い方をしていれば得られたはずの利益 | 5 |
| 埋没費用（サンクコスト） | すでに支払って戻らない費用。判断の根拠にしてはいけない | 1, 20 |
| 感応度分析 | 売上・単価・原価が一定割合動いたとき、利益がどう変わるかを試すこと | 20 |
| レシピ原価 | 1品に使う材料の原価を積み上げたもの。メニューの価格の基礎 | 3 |
| 棚卸し | 在庫を数えて金額を確定する作業。材料費の正確な計算に必要 | 16 |
| 期首在庫・期末在庫 | 期間の始め・終わりに残っている在庫の金額 | 3, 16 |

## 21.2 オペレーション（店の回し方）

| 用語 | 定義 | 扱う章 |
| --- | --- | --- |
| 席数 | 客が座れる席の数。店の面積で上限が決まる | 1, 8 |
| 回転率 | 1日の客数（人）÷ 席数。1席が1日に何人使ったか（人数ベース） | 8 |
| 組回転率 | 1日の組数 ÷ 席数。人数ベースの回転率と混ぜない | 8 |
| 席稼働率 | 延べ使用席時間 ÷（席数 × 営業時間） | 8 |
| 平均滞在時間 | 客が着席してから退席するまでの平均時間 | 8 |
| 席あたり売上 | 売上 ÷ 席数 | 8 |
| 席時間あたり売上 | 売上 ÷ 延べ使用席時間。滞在時間の違う業態を比較できる | 8 |
| 提供リードタイム | 注文から提供までの時間 | 8, 19 |
| 離脱率 | 待ち列から離れた数 ÷ 並んだ数。機会損失の指標 | 8 |
| 機会損失 | 売れたはずなのに売れなかった分の損失。満席時の離脱、品切れなど | 8 |
| ロス率 | 廃棄額 ÷ 仕入額 | 17 |
| 歩留まり | 仕入れた食材のうち、実際に使える割合 | 3 |
| 発注点 | 在庫がこの水準を切ったら発注する量。1日使用量×リードタイム＋安全在庫 | 16 |
| 安全在庫 | 需要の変動や納品遅れに備えて余分に持つ在庫 | 16 |
| リードタイム | 発注から納品までの日数 | 16 |
| 検収 | 納品された品の数量・品質・温度を確認して受け取る作業 | 16 |
| 目利き | 食材の品質を見極める力 | 16 |
| 先入れ先出し（FIFO） | 納品の古いものから使う保管の原則 | 16 |
| 仕込み | 営業中に素早く提供できるよう、あらかじめ食材を切る・煮る・味を付けておく作業 | 17 |
| 下処理 | 仕込みの前段の洗浄・皮むき・芯取り・下味など | 17 |
| 盛り付け | 調理した料理を皿に配置して提供できる状態にすること | 17 |
| メニューエンジニアリング | 粗利額と販売数の2軸でメニューを評価する手法 | 17 |
| スター | 粗利が高く、よく売れる商品。維持する | 17 |
| プラウホース（金のなる木） | 粗利が低いが、よく売れる商品。原価見直しの対象 | 17 |
| パズル | 粗利が高いが、売れない商品。売り方の改善対象 | 17 |
| ドッグ | 粗利が低く、売れない商品。廃止の候補 | 17 |
| 標準化 | レシピ・手順・接客を揃え、誰でも同じ品質にすること | 14 |
| アイドルタイム | 客数が落ち、席が空く時間帯 | 15 |
| 必要労働時間 | 予測客数 × 1人あたりの作業時間 ÷ 効率 | 4 |
| 人時売上 | 売上 ÷ 総労働時間（再掲） | 4 |

## 21.3 集客・マーケティング

| 用語 | 定義 | 扱う章 |
| --- | --- | --- |
| ファネル | 認知→興味→来店→満足→リピート→紹介の段階構造 | 15 |
| 商圏 | 客が来る地理的な範囲。業態で広さが変わる | 15 |
| 新規客獲得コスト | 集客費用 ÷ 新規客数。LTVと比較する | 15 |
| LTV（顧客生涯価値） | 1人の客が生涯で使う金額。客単価 × 来店頻度 × 継続期間 | 8, 15 |
| リピート率 | 来た客がもう一度来る割合 | 8, 15 |
| 来店頻度 | 1人が一定期間に来店する回数 | 8, 15 |
| MEO（Map Engine Optimization） | 地図検索での表示を最適化する施策。Google マップ等 | 15 |
| 共食い | 同一運営者の複数店舗が同じ需要を奪い合うこと | 15 |
| 会員売上比率 | 会員の売上 ÷ 全体の売上。会員施策の効き具合を見る | 15 |
| コンバージョン率（CVR） | ある段階から次の段階に進んだ割合 | 15 |

## 21.4 法規・制度

| 用語 | 定義 | 扱う章 |
| --- | --- | --- |
| 営業許可 | 食品衛生法にもとづき、保健所の許可を受けて営業する制度 | 10 |
| 営業届出 | 許可を要しない業種について、保健所に届け出る制度。許可とは別 | 10 |
| 食品衛生法 | 食品の安全性を確保する法律。営業許可・HACCP・衛生管理の根拠 | 10, 12 |
| 食品衛生申請等システム | 営業許可・届出の申請をオンラインで行う仕組み | 10 |
| 食品衛生責任者 | 施設ごとに設置が求められる、衛生管理の責任者 | 10 |
| HACCP（ハサップ） | 危害要因を分析し、重要な工程を継続的に管理する衛生管理の手法 | 12 |
| 衛生管理計画 | HACCPに沿った衛生管理の内容を定めた計画。作成・周知・記録・検証が必要 | 12 |
| 重要管理点（CCP） | 危害を防ぐために特に管理すべき工程。加熱温度・時間など | 12 |
| 一般衛生管理 | 日常的に行う衛生管理。清掃、健康管理、器具の洗浄など | 12 |
| 特定原材料 | アレルギー表示が義務づけられる原材料。品目の追加・見直しが続いている | 11 |
| 受動喫煙対策 | 健康増進法にもとづく、望まない受動喫煙を防ぐ措置 | 10 |
| 防火対象物 | 消防法の対象となる建築物等。用途と収容人員で設備義務が決まる | 10 |
| 収容人員 | 建築物に収容できる人数。消防設備の算定基礎 | 10 |
| 変形労働時間制 | 繁忙期と閑散期で労働時間を平準化できる制度。要件を満たす必要がある | 13 |
| 割増賃金 | 時間外・深夜・休日の労働に支払う、通常より高い賃金 | 13 |
| 軽減税率 | 飲食料品などに適用される低い税率。持ち帰りと店内飲食で判定が変わる。令和9年4月からの飲食料品の税率引下げが国税庁から公表されている（詳細は第18章） | 18 |
| インボイス制度（適格請求書等保存方式） | 消費税の仕入税額控除に適格請求書が必要となる制度 | 18 |
| 適格請求書 | インボイス制度で定められた記載事項を満たす請求書 | 18 |

## 21.5 経営管理

| 用語 | 定義 | 扱う章 |
| --- | --- | --- |
| KPI（重要業績評価指標） | 経営の状態を測り、判断につなげるための指標 | 19 |
| 先行指標 | 将来の結果を予測する指標。予約数、稼働率、提供時間など | 19 |
| 遅行指標 | 結果として後から分かる指標。売上、営業利益など | 19 |
| 指標の木構造 | 上位の結果指標から下位の原因指標へ分解した構造 | 19 |
| ベンチマーク | 比較の基準となる外部の値。業界平均など | 19 |
| 現状値（ベースライン） | 施策を始める前の実測値。効果測定の基準 | 19 |
| 事業継続計画（BCP） | 災害や障害のときに、事業をどう続けるかを決めた計画 | 20 |
| 撤退判断 | 事業をやめるか続けるかの判断。埋没費用ではなく将来の見込みで決める | 20 |

## 21.6 確度の表記

| 表記 | 意味 |
| --- | --- |
| 確定 | 一次資料または公的機関の資料で直接確認した |
| 高 | 一次資料で確認した |
| 中 | 間接的な資料、または単一の資料 |
| 一般知識（未検証） | 業界一般の知見。特定の数値の根拠にはしない |
| 未取得 | 取得を試みて失敗した。数値は示さない |
