# よくある質問

読者から出やすい疑問と、短い回答をまとめました。詳しくは各章を参照してください。

## 開業について

### Q. 飲食店を開くのに資格は必要ですか

国家資格は必要ありません（調理師免許がなくても開業できます）。ただし、**食品衛生法にもとづく営業許可**が必要です。業態によっては別の許可や届出も必要になります。

- 営業許可と営業届出の違い → [第10章](10-kyoka-hourei.md)
- 食品衛生責任者の設置が求められる場合があります。保健所に確認してください。

### Q. 開業前に何を確認すればよいですか

窓口は4つです。**物件の契約前**に相談してください。内装を作った後に基準を満たしていないと分かると、改装費が二重にかかります。

1. 保健所: 営業許可、施設基準、HACCP
2. 消防署: 防火対象物、消防用設備、収容人員
3. 税務署: 開業届、消費税、インボイス
4. 労働基準監督署: 労働時間、賃金

→ [第9章](09-kaigyo-junbi.md)、[第10章](10-kyoka-hourei.md)

### Q. 資金はどれくらい必要ですか

**一概に言えません。** 業態、立地、居抜きかスケルトンか、席数で大きく変わります。本資料では金額を示していません。

必要なのは「初期投資額」と「運転資金」を分けて考えることです。運転資金は、最低でも1〜2か月分の固定費と仕入れの支払いを賄える額が目安とされますが、これは実務慣行であり、自店の支払サイトから個別に計算すべき値です。

→ [第7章](07-cashflow.md)、[第9章](09-kaigyo-junbi.md)

## 数字について

### Q. 原価率の目安は何%ですか

**本資料では目安の数値を示していません。** 理由は2つあります。

1. 原価率は業態で大きく異なります。寿司・ステーキなどの素材型は高く、カフェ・バーなどの空間型は低くなります。単一の平均値に意味がありません。
2. 公的な業種別統計（中小企業実態基本調査など）を、本資料の作成時に取得できませんでした。

**他業態の平均と比べても意味がありません。** 比べるべきは、同じ業態の競合と、自店の過去実績です。

→ [第3章](03-zairyo-hi-genka.md)

### Q. 損益分岐点の計算が難しく感じます

式は1つだけです。

```
損益分岐点売上 = 固定費 ÷（1 − 変動費率）
```

必要なのは、**費用を固定費と変動費に分けること**だけです。「売上が0になったとき、この支払いは発生するか」で分けます。

数値例と章末問題は [第6章](06-soneki-bunkiten.md) にあります。

### Q. 回転率と稼働率は何が違うのですか

| 指標 | 意味 | 上げ方 |
| --- | --- | --- |
| 回転率 | 同じ席が何人使ったか（人数ベース） | 滞在時間を短くする |
| 稼働率 | 席が埋まっていた時間の割合 | 空いている時間に客を増やす |

昼のピークが満席で夜がガラガラなら、回転率は限界で、稼働率に伸びしろがあります。**時間帯別に測らないと、どちらが課題か分かりません。**

→ [第8章](08-kyaku-tanka-kaiten.md)

### Q. 客単価を上げるべきか、客数を増やすべきか

**どちらか一方だけを見ると失敗します。** 客単価を上げると客数が減り、回転を上げると滞在時間が短くなって追加注文が減ります。4つの数字はトレードオフの関係にあります。

比較するときは「**席時間あたり売上**」（売上 ÷ 延べ使用席時間）で見ます。長時間滞在型の高単価店と、短時間の高回転店を公平に比べられます。

→ [第8章](08-kyaku-tanka-kaiten.md)

### Q. 黒字なのに現金が足りません

**黒字倒産**は実際に起きます。原因は入金と支払いの時期のずれです。

- クレジットカード決済の入金は翌月
- 食材の支払いは翌月払い
- 在庫が増えると現金が減る
- 減価償却費は費用だが現金は出ていない

→ [第7章](07-cashflow.md)

## 運営について

### Q. 従業員が辞めてしまいます

離職には見えにくいコストがかかります。採用費、研修費、戦力化までの生産性低下、既存スタッフの負荷増を合わせると、1人あたり20万円以上になることがあります（説明用の試算）。

打ち手は「採用前のすり合わせ」「初期研修」「シフトの希望反映」「評価の透明化」などです。**自店の退職者への聞き取り（exit interview）が最も確実な情報源**です。

→ [第14章](14-saiyo-kyoiku.md)

### Q. 食品ロスを減らすには

ロスは4種類に分かれ、原因が違えば対策も違います。

| 類型 | 主な原因 | 対策 |
| --- | --- | --- |
| 仕込みロス | 歩留まりの悪い調理 | 調理法の改善、使い切りのレシピ |
| 売れ残りロス | 需要予測の誤り | 仕込み量の調整 |
| 食べ残しロス | 量が多い、味が合わない | 量の調整、持ち帰り |
| 返品・期限切れ | 発注精度、在庫管理 | 発注点の見直し、先入れ先出し |

**ロスと品切れはトレードオフ**です。ロスを減らしすぎると品切れが増えます。品切れの損失は粗利で計算するため、廃棄の損失より大きく出ます。

→ [第17章](17-loss-menu.md)

### Q. どの数字を毎日見ればよいですか

**日次で4つ**に絞るのが現実的です。

1. 売上
2. 客数
3. 客単価
4. 席稼働率

月次では、原価率・人件費率・FL比率を見ます。すべてを見ようとすると、どれも見なくなります。

→ [第19章](19-kpi.md)

### Q. 数字が苦手でも経営できますか

**測ることから始めれば大丈夫です。** 最初からシステムを入れる必要はありません。手作業で1〜2週間記録すれば、現状値の桁は分かります。

測る項目が固まっていない段階でシステムを選ぶと、要らない機能を買うことになります。

→ [第19章](19-kpi.md)

## この本について

### Q. この本は法的に有効ですか

**いいえ。** この本は法的・税務的・会計的な助言ではありません。許可申請、労務、税務の判断は、保健所、社会保険労務士、税理士に確認してください。

### Q. なぜ出典のない数値がないのですか

出典のない数値は、一人歩きして誤った目標設定に使われるためです。「原価率は30%が目安」という情報だけを持った店が、自店の業態に関係なく30%を目標にしてしまう、という事故が起きます。

この本は、**数値そのものより、数値の作り方**を提供することを優先しています。

### Q. 業界平均を知りたい場合はどうすればよいですか

公的統計を直接確認してください。本資料の作成時に取得を試みて失敗した資料と、その代替経路を [第3章](03-zairyo-hi-genka.md) に記録しています。

- 中小企業実態基本調査（中小企業庁）
- 経済センサス（総務省）
- 政府統計の総合窓口（e-Stat）の統計表（Excel）
- 政府統計 API
