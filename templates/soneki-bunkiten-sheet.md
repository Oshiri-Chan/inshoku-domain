# 損益分岐点シート（テンプレート）

このシートをコピーして、自店の数字を入れてください。記入例は説明用の仮置きです。

## 1. 月次の損益

| 項目 | 金額（円） | 売上比（%） | 区分 |
| --- | --- | --- | --- |
| 売上高 | 1,000,000 | 100.0 | — |
| 材料費 | 300,000 | 30.0 | 変動費 |
| **粗利（売上総利益）** | **700,000** | **70.0** | — |
| 人件費（固定部分） | 300,000 | 30.0 | 固定費 |
| 人件費（変動部分） | 0 | 0.0 | 変動費 |
| 家賃・共益費 | 200,000 | 20.0 | 固定費 |
| 水道光熱費 | 50,000 | 5.0 | 固定費 |
| その他経費 | 50,000 | 5.0 | 固定費 |
| **営業利益** | **100,000** | **10.0** | — |

## 2. 変動費と固定費の集計

| 区分 | 金額（円） | 計算 |
| --- | --- | --- |
| 変動費合計 | 300,000 | 材料費 + 人件費（変動部分） |
| 変動費率 | 30.0% | 変動費合計 ÷ 売上高 × 100 |
| 固定費合計 | 600,000 | 人件費（固定）+ 家賃 + 水道光熱費 + その他 |
| 限界利益率 | 70.0% | 100 − 変動費率 |

## 3. 損益分岐点

| 項目 | 値 | 計算 |
| --- | --- | --- |
| 損益分岐点売上（月） | 857,143円 | 固定費 ÷ 限界利益率 = 600,000 ÷ 0.70 |
| 1日あたり（営業25日） | 34,286円 | 857,143 ÷ 25 |
| 必要な客数（客単価1,200円） | 714人/月 | 857,143 ÷ 1,200 |
| 必要な客数（1日あたり） | 29人/日 | 714 ÷ 25 |
| 安全余裕率 | 14.3% |（1,000,000 − 857,143）÷ 1,000,000 |

## 4. 記入上の注意

- **変動費と固定費の分け方を決めて、固定する。** 分け方が変わると損益分岐点の値が変わります。
- アルバイト人件費は、売上に合わせてシフトを組むなら変動費、固定シフトなら固定費です。どちらに置いたかを明記してください。
- 材料費は**仕入額ではなく使用額**です。`期首在庫 + 仕入 − 期末在庫` で求めます。
- 減価償却費は固定費に含めます。ただし、キャッシュフローを見るときは足し戻します。
- 自社物件の場合、家賃は実際には発生しません。経営判断用には**機会費用**（他に貸した場合の賃料）を置いて比較します。

## 5. 使う頻度

| 頻度 | やること |
| --- | --- |
| 月次 | このシートを埋める。前月・前年同月と比べる |
| 四半期 | 変動費率と固定費の変化を確認する |
| 年次 | 投資判断（改装、システム導入）の前提として使う |
