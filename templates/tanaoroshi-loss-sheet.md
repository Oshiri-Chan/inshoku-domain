# 棚卸し・ロス記録シート（テンプレート）

材料費を正確に把握するための記録シートです。コピーして使ってください。

## 1. 月次の棚卸し

| 項目 | 金額（円） | 備考 |
| --- | --- | --- |
| 期首在庫（前月末） | | 前月の期末在庫を転記 |
| 当期仕入 | | 仕入伝票の合計 |
| 期末在庫（当月末） | | 実地棚卸しの金額 |
| **材料費（使用額）** | | 期首在庫 + 仕入 − 期末在庫 |
| 売上高 | | レジの集計 |
| **原価率（%）** | | 材料費 ÷ 売上高 × 100 |

### 計算例（説明用の仮置き）

| 項目 | 金額（円） |
| --- | --- |
| 期首在庫 | 80,000 |
| 当期仕入 | 320,000 |
| 期末在庫 | 100,000 |
| 材料費 | 80,000 + 320,000 − 100,000 = **300,000** |
| 売上高 | 1,000,000 |
| 原価率 | 300,000 ÷ 1,000,000 = **30.0%** |

## 2. 棚卸しの実施ルール

| 項目 | 決めること | 例 |
| --- | --- | --- |
| 頻度 | 月1回以上 | 毎月末の営業終了後 |
| 担当 | 数える人と記録する人を分ける | 店長が数え、オーナーが記録 |
| 範囲 | 冷蔵庫、冷凍庫、常温庫、ドリンク | 全て |
| 単価 | 最終仕入単価か移動平均か | 最終仕入単価 |
| 記録 | 数量と金額の両方を残す | 品目別の一覧 |

**棚卸しをしないと、仕入額をそのまま材料費として扱うことになり、在庫が増えた月に原価率が高く出ます。** 実態とずれた数字で判断すると、仕入れの改善効果を測れません。

## 3. ロスの記録

| 日付 | 品目 | 数量 | 金額（円） | 類型 | 原因 | 対策 |
| --- | --- | --- | --- | --- | --- | --- |
| 11/1 | レタス | 2個 | 300 | 売れ残り | 仕込み過多 | 仕込み量を2個減らす |
| 11/2 | 鶏もも肉 | 1kg | 800 | 期限切れ | 発注量の誤り | 発注点を再計算 |
| 11/3 | 揚げ油 | — | 500 | 仕込みロス | 交換時期 | 交換頻度を記録 |

### ロスの4類型

| 類型 | 内容 | 主な原因 |
| --- | --- | --- |
| 仕込みロス | 下処理で出る皮・芯・端材 | 歩留まりの悪い調理 |
| 売れ残りロス | 作りすぎて売れなかった | 需要予測の誤り |
| 食べ残しロス | 客が残した | 量が多い、味が合わない |
| 返品・期限切れロス | 不良、期限切れ | 発注精度、在庫管理 |

## 4. ロス率の計算

```
ロス率（%）= 廃棄額 ÷ 仕入額 × 100
```

**計算例**: 仕入額500,000円、廃棄額20,000円なら、ロス率は4.0%。

ロス率を1ポイント下げると、その分がそのまま利益になります。**売上を増やさずに利益を増やせる数少ない手段**です。

## 5. 発注点の計算

```
発注点 = 1日あたり使用量 × リードタイム（日数）+ 安全在庫
```

| 品目 | 1日使用量 | リードタイム | 安全在庫 | 発注点 |
| --- | --- | --- | --- | --- |
| 例: 鶏もも肉 | 20個 | 2日 | 20個 | 60個 |

## 6. 使うときの注意

- **ロス率と品切れ率はトレードオフ**です。ロスを減らしすぎると品切れが増えます。
- 品切れの損失は「粗利」で計算するため、廃棄の損失より大きく出ます。100円の食材を捨てる損失と、その食材で作る800円の料理を売れない損失（粗利600円）では、後者が6倍です。
- 食べ残しは、下膳時の目視で5段階評価を記録すると傾向がつかめます。
