# 衛生点検チェックリスト（テンプレート）

日次・週次・月次で使うチェックリストです。コピーして、自店の業態に合わせて調整してください。

> **注意**: このチェックリストは一般的な観点をまとめたものです。法令上の基準ではありません。実際の衛生管理計画は、保健所の指導と業種別手引書に従って作成してください。

## 1. 日次チェック（開店前）

- [ ] 従業員の健康状態を確認した（発熱、下痢、嘔吐、手指の傷）
- [ ] 手洗い設備に石けんとペーパータオルがある
- [ ] 冷蔵庫・冷凍庫の温度を確認し、記録した
- [ ] 食材の期限と外観を確認した
- [ ] 調理器具（まな板、包丁、布巾）が洗浄・殺菌されている
- [ ] 生もの用と加熱済み用の器具が分かれている
- [ ] ゴミ箱に蓋があり、溢れていない
- [ ] トイレが清掃されている（手洗い設備を含む）
- [ ] 虫・ねずみの侵入を防ぐ状態になっている

## 2. 日次チェック（営業中）

- [ ] 加熱料理の中心温度を確認した（必要な場合）
- [ ] 加熱後の食品を常温で放置していない
- [ ] 冷蔵が必要な食材を室温に出しっぱなしにしていない
- [ ] 提供までの時間を管理している
- [ ] 調理中に手洗いを適切に行っている
- [ ] 異物（髪、虫、プラスチック片）の混入がないか確認している

## 3. 日次チェック（閉店後）

- [ ] 調理台、器具、床を清掃・消毒した
- [ ] 食材を適切な温度帯で保管した
- [ ] 廃棄する食材を記録した（ロス記録シートへ）
- [ ] 冷蔵庫・冷凍庫の温度を最終確認し、記録した
- [ ] ゴミを密閉して保管した
- [ ] 翌日の仕込み量を確認した

## 4. 週次チェック

- [ ] 冷蔵庫・冷凍庫の庫内を清掃した（詰め込みすぎていないか確認）
- [ ] 換気扇・フィルターを清掃した
- [ ] 排水口・グリストラップを清掃した
- [ ] 布巾を交換・煮沸消毒した
- [ ] 器具の劣化（傷、割れ）を確認し、交換した
- [ ] 洗剤・殺菌剤の残量と希釈濃度を確認した

## 5. 月次チェック

- [ ] 衛生管理計画の記録を点検した
- [ ] 基準を外れた記録がないか確認し、改善措置の実施を確認した
- [ ] メニューや仕入れ先の変更で、工程が変わっていないか確認した
- [ ] 従業員の健康診断の実施状況を確認した
- [ ] 研修・朝礼での衛生教育を実施した
- [ ] 害虫・ねずみの痕跡（糞、かじり跡）を確認した

## 6. 記録の残し方

| 項目 | 記録すること | 保存期間の目安 |
| --- | --- | --- |
| 温度管理 | 日時、温度、確認者、異常時の対応 | 1年以上 |
| 清掃・消毒 | 日時、場所、実施者 | 1年以上 |
| 健康管理 | 日時、従業員の状態、対応 | 1年以上 |
| 苦情・事故 | 日時、内容、対応、再発防止 | 長期 |

**保存期間は目安です。** 実際の要件は保健所に確認してください。

## 7. 異常があったときの対応

```
異常を発見
  ↓
① 提供を止める（該当する食品を出さない）
  ↓
② 原因を特定する（温度、時間、汚染経路）
  ↓
③ 改善措置を取る（再加熱、廃棄、交換）
  ↓
④ 記録する（何が起きて、どう対応したか）
  ↓
⑤ 再発防止を決める（手順の見直し、教育）
```

**「提供を止める」を最初に置くのが重要です。** 原因を調べている間に提供を続けると、被害が広がります。

## 8. HACCPとの関係

このチェックリストは、HACCPに沿った衛生管理の「一般衛生管理」の部分に対応します。加えて、次の「重要管理」を自店で定める必要があります。

| 項目 | 決めること |
| --- | --- |
| 重要管理点（CCP） | どの工程を特に管理するか（例: 加熱、冷却） |
| 管理基準 | 守るべき数値（例: 中心温度、冷蔵温度） |
| 監視方法 | どう測るか（温度計、目視） |
| 改善措置 | 基準を外れたらどうするか |
| 記録方法 | どこに残すか |
