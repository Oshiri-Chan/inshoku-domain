# 飲食店経営のドメイン知識

飲食店を経営する人、これから開業する人、飲食店向けのシステムやサービスを作る人に向けた、**初学者向けの経営ドメイン知識の資料**です。

専門用語は初出時に説明し、計算式には数値例を付けています。数値には出典と取得日を付け、確認できなかったものは「未取得」と明記しています。

## この資料の特徴

- **用語から始める**: 「FL比率」「回転率」「損益分岐点」を、説明なしに使わない
- **計算できる**: すべての式に数値例を付け、電卓で検算できるようにしている
- **根拠を示す**: 統計には出典・公表年・取得日を付ける。出典のない数値は「一般知識（未検証）」と明示する
- **不明を隠さない**: 取得できなかった統計・法規は「未取得」と書き、推測で埋めない
- **現場で使える**: 各章に「自店で確認すること」のチェックリストと、解答付きの演習がある

## この資料の限界

**必ず読んでください。**

1. **法的・税務的・会計的な助言ではありません。** 許可申請、労務、税務の判断は、保健所、社会保険労務士、税理士に確認してください。
2. **数値例は説明用の仮置きです。** 実在の店舗の実績ではありません。
3. **業界平均の原価率・人件費率は載せていません。** 業態・規模・地域で大きく異なり、単一の平均値を目標にすると判断を誤るためです。代わりに自店の数字を作る方法を書いています。
4. **法規は改正されます。** 制度の内容は確認時点のものです。必ず最新の一次資料を確認してください。
5. **取得できなかった情報があります。** 業種別の原価率・人件費率の公的統計、開業率・廃業率、営業許可の申請書類の詳細、消防法の用途区分などは「未取得」と明記しています。推測では埋めていません。
